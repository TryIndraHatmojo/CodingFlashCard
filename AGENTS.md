## Commit workflow

- Create a Git commit after each completed, coherent coding change. Do not leave all work for one final commit.
- Group related files by purpose and write descriptive commit messages.
- Run checks appropriate to the change before committing, and report the results.
- Commit source files and project documentation; exclude local toolchains, build output, test artifacts, and credentials.
- Preserve existing history. Do not rewrite commits or push to a remote unless the user requests it.
